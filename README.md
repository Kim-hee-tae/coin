# 2인 소켓 비행기 게임 (10단계)

2명이 같은 서버에 접속해 비행기를 조작하며 적군을 격추하는 실시간 게임입니다.

## 핵심 규칙
- **2인 동시 플레이**: 내 비행기 + 상대 비행기가 내 화면에 함께 보입니다.
- **모드 선택**: 게임 시작 전에 `싱글플레이` / `2인 멀티플레이` 선택 가능.
- **시작 카운트다운**: 두 플레이어가 모두 입장하면 마지막 입장 후 **3초 뒤 게임 시작**.
- **미사일 전투**: 플레이어는 `Space`/`Enter`로 미사일 발사. (P1=빨강, P2=파랑)
- **유도미사일 시간 조정**: 유도미사일 아이템 효과는 3초 지속 후 원상복구됩니다.
- **적군도 공격**: 적군이 플레이어를 향해 미사일을 쏩니다.
- **렌더링 개선**: 아군은 실제 비행기 형태(동체/날개/꼬리)로, 적군은 이미지 스프라이트로 렌더링합니다.
- **적군 단계별 외형 변화**: 레벨(1~10)에 따라 적군 비행기 이미지의 색/형태가 달라집니다.
- **유도미사일 아이템**: 특정 적(노란 원 표시)을 격추하면 `H` 아이템이 떨어지고, 먹으면 15초 동안 미사일이 적을 추적합니다.
- **스테이지별 아이템 수량**: 1단계 1개, 2단계 2개 ... 10단계 10개가 순차적으로 등장합니다.
- **보스 시스템**: 해당 단계 졸병을 모두 처치하면 보스 비행기가 등장하고, 보스를 잡아야 다음 단계로 이동합니다.
- **보스 불꽃 미사일**: 보스는 퍼지는 불꽃 탄막을 발사하며, 단계가 올라갈수록 탄 개수가 1개씩 증가합니다.
- **졸병 절반 처치 페이즈**: 졸병을 절반 이상 처치하면 일반 적도 랜덤 퍼짐 미사일을 발사합니다.
- **적 이동 패턴**: 적군은 위→아래로 등장하며, 지그재그/원형/상승-하강 패턴으로 내려옵니다(단계가 높을수록 복잡해짐).
- **폭탄 스킬(B)**: 폭탄 2개까지 사용 가능하며, 사용 시 현재 화면의 졸병 적군이 즉시 격추됩니다(보스 제외).
- **목숨 2개**: 플레이어는 2번 피격까지 버틸 수 있으며, 피격 시 잠깐 무적 상태가 됩니다.
- **피격 판정**: 적 미사일에 맞았을 때 사망(목숨 소진) 처리됩니다.
- **총 10단계**: 단계별 처치 목표를 채우면 다음 단계 진행. (웨이브 증원으로 10단계까지 확실히 진행)
- **웨이브 보정**: 화면 밖으로 사라진 적은 정리되어, 스테이지 목표 처치 수량이 끝까지 채워지도록 다음 적 웨이브가 계속 생성됩니다.
- **승패 판정**: 게임 종료 시 **더 많이 적군을 처치한 플레이어 승리**.
- **점수 표시**: 상단 HUD에 단계, 단계 목표, P1/P2 점수와 생존 상태 표시.

## 배포 방식 (요청사항 반영)
질문하신 것처럼, **모든 플레이어가 소스코드를 가질 필요는 없습니다.**

- 서버 PC: `server.py`만 실행
- 플레이어 PC: 빌드된 실행 파일(`.exe` 또는 단일 바이너리)만 실행
- 싱글플레이는 서버 없이 실행 가능

즉, 소스는 서버/빌드 담당자만 가지고 있고, 플레이어는 실행 파일만 받아서 접속하면 됩니다.

## 파일 구성
- `server.py`: 2명 연결 + 메시지 중계 서버
- `client.py`: 게임 클라이언트(UI, 게임 로직, 렌더링)
- `scripts/build_client_exe.sh`: Linux/macOS용 클라이언트 실행파일 빌드 스크립트
- `scripts/build_client_exe.bat`: Windows용 클라이언트 실행파일 빌드 스크립트

## 1) 서버 실행 (서버 PC)
```bash
python3 server.py --host 0.0.0.0 --port 5000
```

## 2) 클라이언트 실행파일 빌드 (빌드 PC)

### Windows
```bat
scripts\build_client_exe.bat
```
빌드 결과: `dist\AirBattleClient.exe`

### Linux / macOS
```bash
bash scripts/build_client_exe.sh
```
빌드 결과: `dist/AirBattleClient`

## 3) 플레이어 PC에서 실행

빌드된 실행파일만 전달한 뒤 각 PC에서 실행:
- `AirBattleClient.exe` (Windows)
- `AirBattleClient` (Linux/macOS)

실행 시 서버 IP를 물어보면 서버 PC의 IP(예: `192.168.0.10`)를 입력하세요.

> 명령행 인자 방식도 가능:
> `AirBattleClient.exe --host 192.168.0.10 --port 5000`
>
> 서버 없이 싱글플레이로 바로 시작:
> `AirBattleClient.exe --single`

## 조작키
- 이동: 방향키 또는 `WASD`
- 발사: `Space` 또는 `Enter`
- 일시정지/재개: `P`
- 경기 재시작: `R`

## 참고
- 서버 최대 2명 제한.
- 3번째 접속자는 "방이 가득 찼습니다." 메시지를 받습니다.
- 게임 월드는 1번 플레이어 클라이언트가 시뮬레이션하고 2번은 동기화 렌더링을 합니다.
- 게임 중 아무 플레이어나 `P`로 일시정지/재개, `R`로 라운드 재시작 가능합니다.
