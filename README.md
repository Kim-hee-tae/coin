# 2인 소켓 비행기 게임

서로 다른 2명이 같은 서버에 접속해서 비행기를 움직이는 간단한 실시간 게임입니다.
- 내 비행기는 초록색, 상대 비행기는 빨간색으로 보입니다.
- 각자 자신의 화면에서 게임을 하고, 상대 비행기 위치가 내 화면에 동기화됩니다.

## 구성
- `server.py`: 2명 접속을 받아 메시지를 중계하는 서버
- `client.py`: tkinter로 렌더링하는 게임 클라이언트

## 실행 방법

### 1) 서버 실행 (한 명)
```bash
python3 server.py --host 0.0.0.0 --port 5000
```

### 2) 클라이언트 실행 (각자)
같은 네트워크라면 서버 IP를 넣어 실행하세요.
```bash
python3 client.py --host <서버IP> --port 5000
```

로컬 테스트 시 두 터미널에서:
```bash
python3 client.py --host 127.0.0.1 --port 5000
```

## 조작키
- 이동: 방향키 또는 WASD

## 참고
- 서버는 최대 2명만 허용합니다.
- 3번째 사용자가 접속하면 "방이 가득 찼습니다." 메시지를 받습니다.
